# 📋 TRON Staking Platform - Краткий обзор проекта

## 🎯 Описание
Полнофункциональная платформа для управления депозитами USDT TRC-20 с интеграцией Telegram WebApp, бота и админ-панели. Позволяет пользователям делать депозиты, отслеживать прибыль и запрашивать выводы через удобный интерфейс.

## 🏗️ Архитектура

```
Frontend (WebApp) ──────┐
                        │
Telegram Bot ───────────┼──── FastAPI Backend ──── PostgreSQL
                        │                      │
Admin Panel ────────────┘                      ├── Redis
                                               │
TRON Monitor Service ──────────────────────────┴── TronGrid API
```

## 🔧 Компоненты

### Backend (FastAPI)
- **API**: RESTful API для всех операций
- **База данных**: PostgreSQL с SQLAlchemy ORM
- **Аутентификация**: JWT токены для админов
- **Валидация**: Pydantic схемы
- **Мониторинг**: Автоматическая проверка TRON транзакций

### Frontend (Vanilla JS)
- **WebApp**: Telegram WebApp с футуристическим дизайном
- **Админ-панель**: Интерфейс для управления платформой
- **Мультиязычность**: EN, RU, CN
- **Адаптивность**: Мобильное-первое решение

### Telegram Bot (Python)
- **Команды**: /start, /balance, /deposit, /help
- **WebApp кнопка**: Быстрый доступ к приложению
- **Уведомления**: Push-уведомления пользователям
- **Мультиязычность**: Поддержка 3 языков

### TRON Integration
- **TronPy**: Взаимодействие с блокчейном
- **TronGrid API**: Мониторинг транзакций
- **Автоматизация**: Проверка и одобрение депозитов
- **Безопасность**: Валидация всех транзакций

## 📝 API Endpoints

### Публичные:
- `POST /api/auth/telegram` - аутентификация
- `GET /api/user/{id}/balance` - баланс пользователя
- `POST /api/user/{id}/deposit` - создание депозита
- `POST /api/user/{id}/withdraw` - заявка на вывод
- `GET /api/deposit-info` - информация для депозита

### Административные:
- `POST /api/admin/login` - вход админа
- `GET /api/admin/stats` - статистика
- `GET /api/admin/deposits/pending` - ожидающие депозиты
- `PUT /api/admin/deposits/{id}` - обновление депозита
- `POST /api/admin/accruals/bulk` - массовые начисления
